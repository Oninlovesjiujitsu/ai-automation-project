# Authentication and Account Policy

## Password Reset
If a user forgets their password, they must request a password reset link via the login page.
1. Go to the login page and click "Forgot Password".
2. Enter the email address associated with the account.
3. An email with a reset link will be sent.
4. The link expires after 15 minutes for security purposes. If the link expires, the user must request a new one and follow the prompts.

## Two-Factor Authentication (2FA)
We strongly recommend enabling 2FA. If a user loses access to their 2FA device, they must use the backup codes provided during setup. If backup codes are lost, the user must contact support and provide identity verification (e.g., a photo ID) to regain access.
